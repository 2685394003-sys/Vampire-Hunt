# B3 十字斩 (F3)

- 帧数: 10  @ 24 fps
- 尺寸: 1024x1024, RGBA 透明
- 主题: 红色血族 / 顶视角
- 说明: F3 双斜向交叉斩(X形)本体。

## 文件
- frames/  : PNG 序列帧 (cross_slash_0001.png ...)
- contact_sheet.png : 预览拼图
- cross_slash.jsx : After Effects 复现脚本

## 在 AE 中使用
1. 打开 After Effects
2. 文件 > 脚本 > 运行脚本文件... > 选择 cross_slash.jsx
3. 脚本自动建 1024x1024 合成并导入序列帧
4. 如需导出序列: 渲染队列 > 输出模块选 PNG 序列 + RGB+Alpha
