# 玩家数值系统

## 数据分层

- `PlayerMainStats.asset`：策划基础值，只在新一局初始化时读取，不要在运行时修改。
- `PlayerNetworkState`：每名玩家独立的局内状态，由服务器修改并同步给客户端。
- `PlayerStatUpgrade`：升级卡、道具、商店等系统接入局内成长的统一参数。

基础配置位于 `Assets/Resources/GameBalance/PlayerMainStats.asset`。策划修改该资产即可改变下一局的初始值。

## 添加局内升级

升级必须在服务器执行：

```csharp
PlayerNetworkState player = ...;

// 基础攻击 +3
player.ApplyRunUpgrade(new PlayerStatUpgrade(
    PlayerStatType.BaseAttack,
    3f));

// 攻击间隔变为原来的 90%（攻速提升）
player.ApplyRunUpgrade(new PlayerStatUpgrade(
    PlayerStatType.AttackInterval,
    0.9f,
    PlayerStatOperation.Multiply));
```

`Multiply` 使用直接倍率：`1.1` 表示乘以 110%，`0.9` 表示乘以 90%。所有结果都会按属性的合法范围自动钳制。

## 当前规则

- 新局开始时：生命和体力回满，猩红值归零，所有局内强化清空。
- 最大生命或最大体力增加时，会同时补充增加的上限差值。
- 暴击由服务器每次挥砍只判定一次，同一挥砍命中的全部目标共享该次暴击结果。
- `maxHp` 最终会四舍五入为整数，因为现有生命和伤害结算使用整数。
- 击退持续时间和硬直时间尚未出现在策划 CSV 中，暂时作为基础配置的补充字段，不参与局内成长。
