# 血族狂猎 UI 视觉规范 · Silver & Blood

版本：2026-09-12 / 第一版。范围：战斗 HUD、血契与副契选择、小型组件库、Unity 预览入口。

## 1. 视觉基准

用户参考图保存在 `ArtSource/AI/UI/Gothic/Reference.png`。保留旧银金属、暗红血液、哥特八芒徽章、细外框、左上状态与右下四格道具的构图。中央为战斗视野，右上方框使用现有血契构筑摘要，未添加无数据来源的小地图。

金属仅用于边缘与徽章；石纹作为低对比底板；正文保持完整留白。不要在文字后添加血迹、裂纹高光或强发光。主血契与副契必须同时使用文字标签和颜色区分，选中状态同时表现为金色边框与“已选择”。

## 3. 布局

### HUD

- 屏幕边缘 12px 细框，装饰层 PickingMode.Ignore。
- 左上：110px 徽章，横向生命/体力，竖向猩红升级进度。
- 猩红竖槽按本次升级费用归一化；库存文字显示持有量/容量。升级满级后不显示可升级高亮。
- 顶部中央：倒计时与目标。Boss 区位于其下，分别展示生命和格挡。
- 右上：当前血契数量与构筑摘要。
- 右下：4 个108×112道具槽，数量与1～4提示保持实时显示。
- 底部中央保留普攻与冲刺；未接通的重击、神器槽暂隐藏，原查询节点仍保留。

### 血契选择

- 中央窗口宽1160，顶底留安全空间。上排3张342×325主血契，下排3张342×192副契。
- 两排独立选择，任意主契可搭配任意当前副契；不作同列绑定。
- 选择摘要位于按钮上方。未选齐两项时确认禁用。
- 刷新沿用既有规则与服务器价格；更新Offer时清空选择。
- 默认、悬停、焦点、选中、禁用五种状态均有视觉反馈。
- 中文自动换行，长描述需在目标分辨率实测，不能依靠生成图中的小字。

## 4. 图片素材与组件

源PNG位于 `Assets/VampireHunt/Art/UI/Gothic`，由内置图像工具分别生成。后端模型未公开，未声称指定了GPT-image-2.5。提示词见 `ArtSource/AI/UI/Gothic/PROMPTS.md`。

| 素材 | 用途 | 导入规则 |
| --- | --- | --- |
| Panel.png | 面板、卡片、道具槽九宫格 | Sprite Single，最大1024，Clamp，无MipMap，无压缩 |
| Crest.png | 玩家徽章、角饰、通用血契图标 | Sprite Single，最大512，保留Alpha |
| BloodBlade.png | 剑气血契系列图标 | Sprite Single，最大512 |
| EnemySigil.png | 副契通用图标 | Sprite Single，最大512 |

九宫格使用USS切片：四边110，slice-scale 0.28。原始PNG仍保留原尺寸，不以导入后的分辨率覆盖母图。透明徽章不可替换成带棋盘底的文件。

组件由 `GothicTheme.uss` 和 `GothicComponents.uxml` 提供：九宫格面板、徽章、生命/体力条、血契卡、副契卡、按钮状态、四格道具槽、文字与语义色。样例只使用这4张母图，不复制多套相似纹理。

当前已有独立Icon的血契/副契优先显示其Icon；缺图时使用系列/通用图标。本轮不是54张独立血契插画交付。后续可逐张补图，不改变协议或PactId。

## 5. Unity接入与预览

生产入口：`VH_Player.prefab` 的 UIDocument，引用独立的 `GothicPanelSettings.asset`。Panel参考1920×1080，ScaleWithScreenSize + Expand；不修改共享Core面板设置。

生产树：`VampireHuntHUD.uxml`，先载入旧样式，再载入 `GothicTheme.uss`。保留Presenter查询名称。HUD实时值、物品事件、Boss读模型与血契RPC继续使用原链路；新增图标与摘要只在表现层。

Unity菜单 **Vampire Hunt → UI → Gothic UI Review** 可打开独立预览窗口，切换HUD、血契、组件库及四种分辨率比例。预览使用同一生产UXML/USS、真实血契配置文案与示例数值；点击与刷新只演示状态，不修改游戏资源。

实际玩法：打开SampleScene，启动Host，获得猩红后按Z。先分别选择两项，再确认。数字键1～4仍使用原道具输入。
